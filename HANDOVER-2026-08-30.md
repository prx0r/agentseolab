## What this is

DomainArena: **A/B testing for domain names in the agentic web.**

A name.com-integrated MCP tool that:
1. Searches live name.com inventory
2. Measures which domains AI agents understand (semantic inversion)
3. Recommends the best domain with evidence
4. Safely registers via name.com (fail-closed, idempotent)
5. Configures DNS and produces content-addressed receipts

## Gotchas

1. `urllib` default UA → Groq 403. Always send `User-Agent: DomainArena/1.0`
2. Groq reasoning models need `max_tokens ≥ 300`
3. qwen3.6 wraps output in `<think>` tags — strip before parsing
4. name.com sandbox ≠ production. Sandbox: `api.dev.name.com`
5. `pkill` kills other processes on shared box. Use `kill <PID>`.
6. `sleep` wastes time. Background jobs + check logs later.
7. Secrets in git → GitHub push protection blocks. Remove before push.
8. 93 tests passing — don't break them.
