## Key Architecture Decisions

1. **Agent statements are telemetry, never ground truth** — verifier output is truth
2. **Free models only** — see AGENTS.md for approved list and forbidden list
3. **One variable per experiment** — neutral names, name-description decoupling
4. **Wilson CI** for 2-candidate stats — no bootstrap, no BT until ≥3 candidates
5. **Fail-closed evidence gates** — PROVISIONAL→CONFIRMED→REPLICATED require pv≥2, n≥threshold, cross-family replication

## How to Run Things

```bash
cd /root/agentseolab

# Run pairwise tournament (L0 preference probe)
python3 runner/experiment.py "experiment-name"

# Run canary factory
python3 runner/canary.py --backend opencode --n 3

# Run execution-grounded ASL-001
python3 runner/execution_experiment.py cloudflare 10

# Run across all model families  
python3 runner/model_matrix.py 3

# Check evidence integrity
python3 analysis/audit.py

# View hypothesis ledger
python3 analysis/evidence_library.py

# Run tests
python3 -m pytest tests/test_stats_and_validity.py -q
```
