how this works
DomainArena tests candidate domains against multiple AI agents using blind semantic inversion — agents see only the domain name, never the product description. If an agent can correctly infer what service sits behind a domain without context, that domain transmits meaning effectively.

cross-family testing
Each domain is tested across multiple AI model families (Llama, Mistral, Qwen, DeepSeek). If a domain only works on one model, that's a boundary condition, not a law. DomainArena requires agreement across families for a "match" classification. This is the same methodology used in academic agent-comprehension research.
what's happening
Semantic inversion flips the normal evaluation: instead of asking "is this a good name?" we ask "what does an agent think this name means?" The agent sees only the domain — no description, no website, no context. Its inference is scored against your frozen product intent. Generator/judge separation ensures the tested model never scores itself. This is the same experimental methodology used in academic agent-comprehension research.
Research Findings
counterintuitive discoveries from 16 experiments
What we learned challenges common assumptions about domain naming for AI agents.
finding 1: description seduction is real
Some model families selected broken tools when they had enterprise-sounding descriptions. A tool with a polished description but non-functional API was chosen over a working tool with a plain description. Agent discovery systems can be manipulated by presentation rather than actual capability.
finding 2: position dominates domain choice
In pairwise tests, 87% of agents picked the first option regardless of which domain was shown. TLD effects (.com vs .dev vs .ai) were statistically insignificant within the same position. Order matters more than extension.
finding 3: models disagree materially
Llama 3.3, Mistral Small, and Qwen3 produced different rankings for the same domains. A domain cannot be called "agent-legible" based on one model. Cross-family replication is essential.
finding 4: semantic inversion is a cheap proxy
AgentSearchBench (10,000 agents) shows that description similarity is weaker than execution-grounded performance for ranking. Blind inference is a useful first filter, but execution testing is ground truth.
finding 5: serverless inference drifts
Identical prompts at temperature zero produced materially different choices across time windows. One-shot domain ratings are scientifically weak. DomainArena replicates across windows.

Frontier Evidence
why this matters now
The web is becoming agent-consumed. Domain naming for machines is a new problem that needs measurement, not assumptions.
the shift: humans vs agents
Humans use Google search, see AI-generated answers, and click links. Agents discover services through tool calls, API descriptions, and domain inference. The customer discovering your service may be an AI, not a human. DomainArena measures the agent comprehension layer that traditional SEO ignores.
arxiv: 14.44M agent search requests
A 2026 study analyzing 14.44 million real agent search requests found that agent search is iterative: agents reformulate queries and over half of newly introduced terms were grounded in evidence they had already retrieved. Agents don't just "search once" — they explore systematically. Your domain needs to be discoverable at every step.
arxiv: AgentSearchBench (10,000 agents)
AgentSearchBench contains almost 10,000 real agents and shows an important gap between description similarity and actual execution performance. Execution-aware signals improve retrieval/ranking. "Description sounds relevant" is not sufficient — agents need to verify by doing.
arxiv: position bias in LLM judges
LLM judges have measurable position bias. 87% pick slot 0. DomainArena uses AB/BA position randomization to control for this — the same methodology recommended by Shi et al. (2024) across 12 LLM judges and 100k+ evaluation instances.
the agent web is real
Cloudflare launched Agent Readiness to test whether sites can be discovered by agents. Their Registrar API lets agents search/check/register domains. Google's AI Overviews now answer queries directly. The customer is increasingly a machine. DomainArena measures whether your name works for that customer.
