## What changed and why

The original plan was "build DomainArena → record demo video → submit to hackathon."
That produced a working pipeline but no novel findings.

**The pivot**: DomainArena's real value isn't as a domain-search tool. It's as
a **measurement instrument** for a question nobody has answered:

> *Given a task description, which domain names do AI agents infer are relevant,
> which do they select, and does the hostname itself affect their choice?*

Four independent papers (ToolTweak, Tool Preferences Unreliable, ToolDNS,
PA-Tool) identified that naming drives agent behavior. None built the
measurement tool. That's us.

---

## Two deliverables

### 1. DomainIntelligence MCP server
An MCP tool that AI agents call to find, evaluate, and register domains.
Powered by name.com API. Backed by empirical evidence from our experiments.

```
Agent: "I need a domain for my JSON repair tool"
    ↓ calls domainarena MCP
MCP returns:
  - live inventory matches (name.com Search API)
  - semantic comprehension scores per candidate (CF Workers AI)
  - budget feasibility analysis
  - recommendation with evidence receipt hash
  - [optional] registration after explicit approval
```

This IS the hackathon submission. It uses search+availability+pricing+
registration+DNS = five endpoints, functionally central.

### 2. Agent Domain Preference benchmark (cogym worldpack)
A cogym world where we place N functionally-equivalent services behind
different domain names, give agents tasks, and measure which domains get
selected, invoked, and trusted. Every run produces a content-addressed receipt.

This produces the **dataset**: which names cause correct comprehension,
selection, and invocation across model families.

## Gotchas

1. Use `/root/.cargo/bin/cargo` for wasm32 builds (system cargo lacks target)
2. `setsid … < /dev/null &` for background jobs; bare nohup dies with tool timeout
3. pkill -f matches its own cmdline — use full script path in pgrep
4. Ports 8803/8810 belong to OTHER lanes — use 8805+
5. Telegraph WASM sandbox = fresh memory per call (no runtime state)
6. HF gated datasets: SWE-chat needs access request at the dataset page
7. `re.split` without capture group returns 2 parts not 3
8. Test denominators: divide by count actually evaluated, not hardcoded N
