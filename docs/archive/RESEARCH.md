# Agent SEO Research & Similar Projects

## Key Projects Found

### 1. Moltbook Observatory
**GitHub:** https://github.com/kelkalot/moltbook-observatory
**Stars:** 52
**What:** Passive monitoring and analytics dashboard for Moltbook — the social network for AI agents.

**Relevance:** Directly studies agent behavior, posts, comments, and trends. Collects posts, tracks agents, analyzes trends over time. Has academic citations and datasets on HuggingFace.

**Key insight:** The Observatory silently watches Moltbook, collecting posts, tracking agents, and analyzing trends over time. The longer it runs, the richer the dataset becomes.

**Academic paper:** "The Moltbook Observatory Archive: an incremental dataset of agent-only social network activity" (arXiv:2605.13860)

### 2. GEO: Generative Engine Optimization
**Paper:** https://arxiv.org/abs/2311.09735 (Princeton, KDD 2024)
**What:** The foundational paper that defined GEO — optimizing content for generative AI engines.

**Key findings:**
- Adding statistics with sources: up to 40% visibility lift
- Quotations from named sources: top-performing technique
- Citing external sources: ~22% lift
- Keyword stuffing: performed below baseline

**Relevance:** This is the academic foundation for agent SEO.

## Key Insights

1. **Agent behavior is observable** — Moltbook provides real data on what agents actually do
2. **GEO is measurable** — Princeton paper shows up to 40% visibility lift with specific tactics
3. **Agent preference testing is scientific** — Use controlled experiments, not just LLM opinions
4. **The moat is data** — Accumulated observations of agent behavior become increasingly valuable
5. **Standards are converging** — GEO, MCP, A2A creating new agent-native opportunities
