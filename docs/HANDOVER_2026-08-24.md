## 5. Key inherited scientific laws (do not violate)

From confirmed ledger findings (see `docs/EXPERIMENT_REDESIGN.md` table):
1. Serverless temp=0 is NONDETERMINISTIC across windows → within-run contrasts
   only; family claims need ≥2 window replicates (H-SERVE01).
2. Description CONTRAST drives selection → identical metadata unless metadata is the IV.
3. Position primacy (~87% slot 1) → report position-STRATIFIED estimands always.
4. Name has zero effect under informative descriptions → hostname effects only
   measurable in degraded-description regime (NAMING01 ceiling null).
5. Seduction is family-clustered → never pool before homogeneity test.
6. n≥30/arm for anything above PROVISIONAL.
7. Verifiers must be injective (one candidate can satisfy them).
