# Naming Science Program

## Purpose
Experimentally discover which domain naming patterns cause correct intent inference and successful discovery by agents.

## Seven Designed Experiments (none run yet)
1. Agent search traces collected BEFORE any name shown → search-language corpus
2. Semantic inversion: P(correct intent | domain alone)
3. Pure domain causal effect: hostname-only swap, all else fixed
4. Naming-family tournament: 12 families blinded tournament
5. Metaphor/archetype mapping: learn animal→attribute vectors experimentally
6. Memory tests: recall, recognition, spelling reconstruction
7. Exposure curve: preference at exposure 0/1/3/7

## Measurement Dimensions (11 groups)
Orthography · Phonology · Morphology · Semantics · Archetype · Psychology · Brand · Web · Agent · Legal · Derived metrics
