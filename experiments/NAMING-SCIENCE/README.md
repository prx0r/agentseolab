# Naming Science Program

## Purpose
Experimentally discover which domain naming patterns cause correct intent inference and successful discovery by autonomous agents.

## Seven Designed Experiments (none run yet)
1. Search-language corpus: collect agent queries BEFORE showing any names
2. Semantic inversion: P(correct intent inferred | domain name alone) → semantic_transmission score
3. Domain causal effect: hostname-only swap, everything else identical, AB/BA
4. Naming-family tournament: 12 families blinded tournament (descriptive, action+object, suggestive compound, animal, nature, tool/object, motion verb, myth/place, invented, phonosemantic, blend, contrarian)
5. Metaphor mapping: learn animal→attribute vectors experimentally (no hand-authored bonuses)
6. Memory tests: free recall, recognition, spelling reconstruction, speech-to-domain
7. Exposure curve: preference at exposure count 0/1/3/7 (cold-start vs repeated-exposure tradeoff)

## Measurement Dimensions (11 groups)
Orthography · Phonology · Morphology · Semantics · Archetype · Psychology (fluency/warmth/competence) · Brand (distinctiveness/memorability) · Web (speech-to-domain accuracy, typo risk) · Agent (intent inference, query overlap) · Legal · Derived metrics

## Key Insight
Ranking-effect vs selection-effect must be measured SEPARATELY. A domain that ranks well in search may not be the one agents select when given a choice.
